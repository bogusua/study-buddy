# Solutions / Розв'язки

Тут учень зберігає свої розв'язки практичних завдань з курсу Python.

## Формат іменування файлів

```
lesson_NN_task_MM.py
```

- `NN` -- номер уроку (01, 02, ..., 15)
- `MM` -- номер завдання в уроці (01, 02, 03, ...)

## Приклади

```
lesson_01_task_01.py   # Урок 1, завдання 1
lesson_01_task_02.py   # Урок 1, завдання 2
lesson_05_task_03.py   # Урок 5, завдання 3
```
